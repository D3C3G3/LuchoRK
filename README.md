# LuchoRK


Proyecto TI
Se deberá elaborar una web sobre un grupo musical. La web deberá contar con una portada
atractiva utilizando tecnologías HTML y CSS y con capacidad para albergar las informaciones
más recientes en torno al grupo en cuestión. Las secciones de la portada serán:
Últimas noticias.
Próximas fechas de gira.
Resumen de merchandising.
